AP Computer Science Principles

AP Computer Science Principles

*No Prerequisite
(Instructors: Mr. Nguyen, Mr. Holmes-Williams, Mrs. Calhoun, Dr. Shukla)

  • Programming Fundamentals in Python and JavaScript
  • Web Development: HTML, CSS, JavaScript
  • Computer Systems and Components
  • Digital Information: ASCII code, Pixel RGB data, File Formats, Data Compression
  • Spreadsheets and Data Visualization
  • Ai Concepts and Prompt Engineering
  • Computing Innovations and Impacts of Computing
  • The Internet/Networks, Phishing, Malware, Encryption
✔ Students also receive course credit for Introduction to Software Technology upon completion of this course.

AP Computer Science Applications

AP Computer Science Applications

*Prerequisite: AP Computer Science Principles (90%), AI Concepts, BC Calculus or above, or faculty approval.
(Instructors: Mrs. Rachkovskiy, or Mr. Holmes-Williams)

  • The course aligns to the College Board’s AP Computer Science A course and first semester computer science college courses (Georgia Tech CS 1331, among others). It provides college credit with a 4 or 5 on the AP Exam.
  • Develop/Select appropriate algorithms and data structures to solve problems
  • Code fluently in Java, an object-oriented paradigm programming language, including the following concepts:
    • Iterations/Loops -Concepts of Abstract & Linear Algebra/Number Theory
    • Input/Output -Algorithm Performance/Complexity Analysis/Big O Notation
    • Collections/Lists -Primitive/Reference Object Data Types
    • Methods/Classes -Searching/Sorting Algorithms
    • Conditional Logic -Reading data from a text/.csv file
    • Recursion -Multidimensional Arrays/ArrayLists
  • Read/Program large labs consisting of several classes and interacting objects
  • Study/Discuss ethical and social implications of computer use in our society and historical game changers in Information Technology.

Robotics + Mechatronics

Robotics + Mechatronics

*Year 1 Robotics
(Instructors: Mr. McDonald, Mr. Roberts, Mr. Nguyen)

  • Intro to Aerial Vehicles (Drones).
  • Learn the basics of robotic movement, sensor integration, and programming.
  • Computer vision and autonomous vehicle concepts.
  • Intro to AI for physical devices.
  • 3D printing experience.
  • Build and program robots to meet real-world objectives.
✔ Students will earn +10 points for Course Grade in each Semester.
